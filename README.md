# Análise Exploratória de Dados de Vendas

## Contexto
Este projeto realiza uma Análise Exploratória de Dados (EDA) a partir de um
dataset de vendas, com o objetivo de identificar padrões de desempenho,
lucratividade e impacto de descontos.

## Objetivos
- Analisar o desempenho de vendas por categoria e região
- Avaliar a relação entre desconto e lucro
- Identificar produtos e segmentos com prejuízo

## Ferramentas Utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Principais Análises
- Vendas totais e por categoria
- Lucro por região
- Impacto dos descontos no lucro
- Identificação de vendas com prejuízo

## Principais Insights
- A categoria Technology apresenta maior rentabilidade
- Altos descontos estão associados à redução do lucro médio
- Algumas regiões concentram maior volume de vendas e lucro
- Existem produtos com vendas elevadas, porém com prejuízo

## Conclusão
Os resultados indicam oportunidades de otimização da política de descontos
e foco estratégico em categorias e regiões mais rentáveis.
